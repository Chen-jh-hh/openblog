## 你好世界

这是我的第一篇博客文章，使用 [Hugo](https://gohugo.io/) + [PaperMod](https://adityatelange.github.io/hugo-PaperMod/) 主题搭建。

### 为什么选择 Hugo？

- **构建速度快** — Go 语言编写，毫秒级构建
- **Markdown 原生支持** — 写作体验流畅
- **主题丰富** — 社区活跃，主题质量高
- **免费托管** — GitHub Pages 零成本部署

### 技术栈

| 组件 | 技术 |
|------|------|
| 静态站点生成器 | Hugo |
| 博客主题 | PaperMod |
| 托管平台 | GitHub Pages |
| 自动部署 | GitHub Actions |
